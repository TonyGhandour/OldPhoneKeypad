# AI Usage and Prompt

## AI Tool

ChatGPT (GPT-5.6 Luna)

## Purpose of AI Assistance

AI was used as a development assistant during the project to review,
refactor, and improve the implementation.

The core problem-solving, implementation decisions, testing, and
verification were performed by me.

AI assistance was primarily used for:

- Reviewing code structure and readability
- Identifying potential edge cases
- Suggesting improvements to input validation and error handling
- Improving unit test coverage
- Reviewing the REST API structure
- Improving documentation and README organization

All suggested changes were reviewed, implemented, and tested manually.

## Example AI Prompt

> I am completing a C# coding challenge that requires implementing an
> old mobile phone keypad as a reusable library. The solution should
> follow production-ready coding practices and include unit tests,
> documentation, and an ASP.NET Core Web API wrapper demonstrating how
> customers could consume the library through a REST API.
>
> Review my implementation for correctness, readability, robustness,
> error handling, test coverage, API design, and maintainability.
> Suggest improvements while keeping the core problem-solving and
> implementation decisions mine. Explain the reasoning behind each
> recommendation.

## Verification

All AI-assisted changes were reviewed and tested locally using Visual
Studio. The solution was built successfully and the automated unit
tests were executed to verify the implementation.
